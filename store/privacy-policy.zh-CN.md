# LumaTrace 隐私政策

**生效日期：2026 年 8 月 10 日**

LumaTrace Performance Lab（以下简称“LumaTrace”）是一款本地优先的 Windows 与 Android 性能测试应用。本政策说明应用会处理哪些信息，以及用户可以如何控制这些信息。

## 在本机处理的数据

为了完成用户发起的测试，LumaTrace 可能在用户设备上处理：

- 用户选择的 Windows 进程名称和进程标识符；
- 用户选择的 Android 应用包名和已经由用户授权的设备连接信息；
- 性能指标、时间戳、测试名称、标记和指标可用性信息；
- 在本机生成的报告和经过脱敏的诊断事件；
- 仅在用户为该次测试主动勾选日志导出时生成的会话日志。

这些信息只用于执行用户要求的测试、显示结果、诊断本机采集问题和生成用户要求的报告。

## 本地优先与网络访问

LumaTrace 将测试数据保存在本机应用数据目录中，桌面应用与配套服务仅通过同一台电脑的环回地址通信。LumaTrace 不提供 LumaTrace 云端账号，默认不会把性能指标、报告、诊断信息或会话日志上传到由 LumaTrace 运营的云服务。

只有在用户点击对应链接后，应用才会打开 LumaTrace GitHub 支持页面等外部网站。Android 测试会使用用户本机安装的 Android Debug Bridge（ADB），并使用已经由用户授权的设备连接。

## 可选会话日志

日志导出默认关闭，并且必须由用户针对某次测试单独勾选。

- Android 测试会请求该次测试时间范围内、经过目标过滤的 ADB logcat 记录，并在保存前进行大小限制和脱敏。
- Windows 测试会写出带时间戳、经过脱敏的 LumaTrace 会话事件，不会导出全部 Windows 系统日志。

可选日志保存在用户选择的报告目录下、对应测试的独立文件夹中。LumaTrace 不会上传这些日志。此功能不会收集 Android bugreport、设备范围 syslog、账号凭据、身份验证 token、浏览器 cookie 或密码。

报告和可选日志仍可能包含用户或其组织可以识别的应用名称、包名、测试标签或被测应用自己写入的消息，因此分享前应由用户检查内容。

## 保存期限与删除

本地测试数据会保留在设备上，直到用户将其删除或清除应用数据。用户可以在应用内单独删除或批量删除已完成的测试结果。正在运行的测试和用户先前已经导出的报告文件夹不会被批量删除功能移除。

报告目录由用户控制。用户可以删除对应测试文件夹，从而删除已经导出的报告和可选日志。关闭或卸载 LumaTrace 后，用户还可以从 Windows 应用数据位置删除剩余的本地应用数据。

## 分享与第三方

LumaTrace 不会出售个人信息，也不会把本机采集的性能数据发送给广告网络或数据经纪商。只有在用户主动分享导出文件、打开第三方支持网站，或法律要求披露时，信息才可能交由其他主体处理。

用户访问 GitHub 或提交支持问题时，适用 GitHub 自己的隐私条款。请勿在公开 Issue 中提交账号凭据、token、隐私路径、未经检查的原始日志或其他敏感信息。

## 安全措施

桌面应用和本机配套服务之间使用仅保存在内存中的本地授权 token。该 token 不会写入报告、日志、URL 或浏览器存储。诊断和可选日志导出会执行脱敏与输出大小限制。由于用户创建的文字或第三方应用日志仍可能含有敏感内容，分享前检查仍然很重要。

## 儿童隐私

LumaTrace 是面向性能测试的技术工具，并非专门面向儿童，也不会有意运营收集儿童个人信息的服务。

## 政策变更

如有重大变更，我们会在本仓库发布新版本并更新生效日期。
