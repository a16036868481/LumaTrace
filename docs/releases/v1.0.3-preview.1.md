# LumaTrace 1.0.3 Windows Preview

## 下载与使用

本次发布面向 **Windows 11 x64**，支持测试 Windows 应用/游戏进程与连接的 Android 手机。包含 **101 种语言/地区选项**，首次启动默认英文，可在左下角切换语言。当前不支持 iOS。

- **安装版：** 下载 `LumaTrace-1.0.3-windows-x64-setup.exe` 并安装。
- **便携版：** 下载 `LumaTrace-1.0.3-windows-x64-portable.zip`，完整解压后运行 `lumatrace-desktop.exe`，请保留同目录的 `binaries` 文件夹。
- **微软商店：** [打开商店页面](https://apps.microsoft.com/detail/9P3KNQZMFBM8)。商店当前版本可能与 GitHub 预览版不同。
- **使用说明：** [中文指南](https://github.com/a16036868481/LumaTrace/blob/main/docs/user-guide.zh-CN.md) · [English guide](https://github.com/a16036868481/LumaTrace/blob/main/docs/user-guide.md)

软件自带 Node.js 运行环境，普通用户不需要安装 Node.js 或 pnpm。**ADB 和 PresentMon 未打包：** Android 测试需要安装 ADB、开启 USB 调试并授权电脑；Windows FPS/帧时间需要可用的 PresentMon 和系统权限。缺少某项条件不会伪造该指标。

### 本次更新

- 简化 Windows/Android 测试流程，增加设备发现、应用识别和采集启动的加载提示。
- 重新整理测试结果：按流畅度、应用资源和设备指标分组，支持单独删除或清空已完成的测试；异常中断的旧测试可恢复为结束状态。
- 每次测试的 HTML、CSV、JSON 报告与可选日志归入独立文件夹，支持自选报告目录和多语言报告、性能总结。
- 可选日志默认关闭；Android 提供经脱敏的 ADB logcat，Windows 提供带时间的 LumaTrace 会话/采集事件记录，不冒充被测应用的私有日志。
- 增加一键修复和 GitHub 问题反馈入口，移除 iOS 测试代码。

### 下载前请注意

这是**未签名预览版**，不是已完成生产签核的稳定版。Windows 可能提示未知发布者或 SmartScreen 警告。请核对来源，并用附件 `SHA256SUMS.txt` 检查文件完整性；不要关闭系统防护。安装版可能需要联网安装 Microsoft WebView2；便携版需要电脑已有 WebView2 Runtime。

FPS、GPU、功耗、温度等指标受设备、驱动、应用和权限影响；未采集到的值保持 N/A。设备级读数不等同于单个应用用量。报告性能总结仅供参考。所有测试数据默认保存在本机，分享日志或报告前仍请检查敏感信息。

## English

This **unsigned Windows 11 x64 preview** tests Windows processes and connected Android apps. It includes **101 language/region choices**, defaults to English on first launch, and bundles Node.js so end users do not need a development environment. iOS is not supported.

Choose the **setup EXE** to install, or extract the entire **portable ZIP** and run `lumatrace-desktop.exe`. Keep the `binaries` directory alongside it. ADB and PresentMon are **not included**. Android requires ADB, USB debugging, and device authorization; Windows FPS/frame time requires supported PresentMon capture and system permissions. The installer may download Microsoft WebView2 when missing; portable use requires WebView2 Runtime already installed.

Highlights include a streamlined Windows/Android workflow, perceptible collection loading states, clearer grouped results, individual/bulk result deletion, interrupted-session recovery, per-test report folders, localized reports and performance summaries, opt-in sanitized logs, and local repair/bug-report actions.

Android log export uses sanitized ADB logcat. Windows logs contain timestamped LumaTrace collection/session events, not private logs from the tested app. Missing measurements remain N/A, device-level readings retain their scope, and performance ratings are guidance rather than benchmark scores.

This is not a signed production release. Verify downloads with `SHA256SUMS.txt` and do not disable Windows protection. [Microsoft Store distribution](https://apps.microsoft.com/detail/9P3KNQZMFBM8) is separate and may offer a different version. Review reports/logs before sharing them.
