# Local Auth Token

Packaged LumaTrace uses a one-time local auth token for desktop-to-sidecar communication.

## Rules

- Generated by Tauri at startup.
- Stored in Rust app state memory.
- Exposed to the frontend only through a Tauri command.
- Used as a Bearer token for REST.
- Used as a WebSocket subprotocol token for streams.
- Passed from the Tauri supervisor to the sidecar through `LUMATRACE_AUTH_TOKEN`, not through the sidecar command line.
- Not written to `VITE_` variables.
- Not written to localStorage.
- Not placed in URLs.
- Not placed in sidecar launch arguments.
- Not written to logs, reports, diagnostics, or exported bundles.
- Redacted from crash recovery excerpts, log rotation metadata, sidecar manifests, and packaging diagnostics exports.

Development mode can continue to use `VITE_API_BASE_URL` and `VITE_WS_BASE_URL` without auth. That fallback is for local development only.

## Failure Modes

- Missing REST token: `AUTH_REQUIRED`.
- Invalid REST token: `AUTH_INVALID`.
- Missing or invalid WebSocket token: stream closes with the auth error reason.

The token is not a cloud credential. It only protects the local packaged sidecar from unrelated localhost callers.
